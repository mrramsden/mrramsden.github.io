Mission 2

Binary lights

About 10 minutes✔ Done

Each light has a place value: 16, 8, 4, 2 and 1. A light that is on is a binary 1. Add up the place values of the lights that are on to get the denary number.

Example: 01101 means 8 + 4 + 1 = 13.

Mission 3

Build a binary quiz machine

About 15 minutes✔ Done

You're going to turn a micro:bit into a quiz for a friend. Button A shows a number in binary on the top row of lights. Your friend works it out, then presses button B to see the answer in denary.

Step 1: choose your secret number

Pick any whole number from 1 to 31. Work out its binary on paper or with the lights in Mission 2. The top row of the micro:bit has 5 lights, just like Mission 2: 16, 8, 4, 2, 1 from left to right.

Step 2: build it in MakeCode

Start a New Project and call it Binary Quiz. Build these three stacks. The coloured label tells you which drawer each block is in.

  1. on start is already there. Drag in Basic show icon and pick a picture, so you know it's ready.
  2. From Input drag out on button A pressed. Put a Basic show leds inside it and click the top row squares to show your number in binary. The example above shows 13 (01101).
  3. Drag out another on button A pressed and change the A to B. Put Basic show number inside and type your secret number.
  4. Test it on the simulator: click button A on the virtual micro:bit, then button B. Does B show the number you meant?
If it doesn't work:
  • Are your blocks inside the event blocks? A block on its own looks faded and won't run.
  • Did you change the second button from A to B?
  • Simulator looks stuck? Click the restart button (the circular arrow) underneath it.
  • Nothing scrolling? Wait for the icon to finish, then click the button again.

Step 3: prove it works

Type the number button B shows, and click the lights to match what button A shows. If they match, you win the trophy.

⭐ Stretch: more questions

Add a second question. Use Input on shake to show another binary number, and on button A+B pressed to show its answer. The simulator grows a SHAKE button and an A+B button when you use them. Ask the person next to you to try your quiz on your screen.

Mission 4

Build a counter

About 15 minutes✔ Done

Counters are everywhere: step counters, people counters on shop doors, score boards. Yours uses a variable called count to remember the number, just like the dice and the dimmer switch you built before.

Step 1: make the variable

Start a New Project called Counter. Open Variables, click Make a Variable... and name it count (all lower case).

Step 2: build it

  1. on start: Variables set count to 0, then Basic show number. Drag the round count block from Variables into the show number gap.
  2. on button A pressed: Variables change count by 1, then show number with count in the gap.
  3. on button B pressed: set count to 0, then show number with count in the gap.
  4. Test it on the simulator by clicking buttons A and B.
Input, process, output: pressing a button is the input. Adding 1 to count is the process. The number on the lights is the output.
If it doesn't work:
  • Is it always showing 0? Check you used change count by 1, not set count to 1.
  • Is it showing 0 forever? Check the round count block is in the show number gap, not the number 0.
  • Is your variable spelt the same everywhere? Use the drop-down on each block to pick count.
  • Blocks faded? They must sit inside an event block.

Step 3: prove it works

🏆 Legend challenge: show the count in binary

Can your counter show its number in binary on the top row instead? This uses the place value method: check the biggest place value first. If the number is big enough, turn that light on and take the place value away. Then move to the next one.

You need one more variable called n, so your program can take numbers away without changing count. Change your on button A pressed to this. if is in Logic, the ≥ and > comparisons are in Logic too (click the = to change it), and plot x y is in Led. clear screen is in Basic under ...more.

Also put clear screen in place of show number in on start and on button B pressed, so the old number disappears. Right-click a block and choose Duplicate to save time on the five if blocks.

Prove it: click B on the simulator, then click A eleven times. Click the lights below to match your top row.
