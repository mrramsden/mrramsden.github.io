What order does merge sort really run in?

Step through the recursive code one call at a time and watch the call stack grow and shrink. Then switch to the textbook picture and compare the two orders.

This is the picture most textbooks draw: every list on a level is split at once, then every pair is merged at once. The recursive code never runs in this order. It finishes the whole left side before it touches the right. Switch back to How Python runs it to compare.
